Twitch account

Connected: . No ads on the channels you're subscribed to.

Connect your account to enjoy your subscriptions without ads.

Where to find the token?
  1. On a computer, open twitch.tv while logged in.
  2. Press F12, then the Application tab (Chrome, Edge) or the Storage tab (Firefox).
  3. Cookies → https://www.twitch.tv → row auth-token.
  4. Copy its value (30 letters and digits) and paste it here.

This token gives access to your account: it stays on the box and is never shown again. It stops working if you log out of Twitch in that browser.

Followed channels

For the Following tab of the TV menu, the box needs your own Twitch app (free, one time).

Create the app
  1. Go to dev.twitch.tv/console/apps → Register Your Application (two-factor authentication must be enabled on your account).
  2. Any name (unique on Twitch), OAuth Redirect URL http://localhost, category Other.
  3. Client type Public: only the Client ID is needed. With Confidential, also paste the secret.
  4. Copy the Client ID here.

YouTube account

For the TV menu's Subscriptions row, the box needs your own Google app (free, one time).

Create the app
  1. On console.cloud.google.com, create a project, then enable YouTube Data API v3 (APIs & Services → Library).
  2. Google Auth Platform: audience External, data access scope youtube.readonly, then Publish app (otherwise Google disconnects the box every 7 days).
  3. Clients → Create client, type TVs and Limited Input devices.
  4. Paste the Client ID and the Client secret into the fields below.

App saved. Allow the box to read your subscriptions (read-only).
