YouTube account

For the TV menu's Subscriptions row, the box needs your own Google app (free, one time).

Create the app
  1. On console.cloud.google.com, create a project, then enable YouTube Data API v3 (APIs & Services → Library).
  2. Google Auth Platform: audience External, data access scope youtube.readonly, then Publish app (otherwise Google disconnects the box every 7 days).
  3. Clients → Create client, type TVs and Limited Input devices.
  4. Paste the Client ID and the Client secret into the fields below.

Sound output

Automatic: USB or Bluetooth headphones or speakers come first, otherwise the TV connected over HDMI / DisplayPort.

Plex

Your Plex server in the TV menu (a Plex tab): resume, next episodes, recent additions, search. Progress follows on your other Plex apps.

Token (if the server asks for one)

Not needed if Plex lets the box's network in without signing in: Plex, Settings, Network, "List of IP addresses and networks that are allowed without auth" (for example 192.168.1.0/255.255.255.0). Otherwise the X-Plex-Token of your account: in Plex on the web, "Get info" on a video, "View XML": it ends the link.

Companion app address

Empty: the box's address on the local network. Domain name (https://…, behind a reverse proxy): required to install the companion app as an app on the phone.
